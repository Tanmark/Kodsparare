# Kodspåraren
Ett studieverktyg jag byggde inför det praktiska provet i kursen
Teknik för digitala plattformar (IHM, Customer Data Developer).

**Testa:** https://<Tanmark>.github.io/kodspararen/

## Vad den gör
- **Spåra koden** – stega igenom kursappens ”app.js” rad för rad och se
  vad som händer i Console, Network, Local Storage och på servern.
- **Buggjakt** – 14 planterade fel. Förutsäg utfallet innan du ser facit.
- **Ordlista** – 247 begrepp från klient och nätverk till samtycke och tracking.
- **Förhör** – 400 flervalsfrågor där felsvaren är vanliga missförstånd.

## Om bygget
En enda HTML-fil utan beroenden. Byggd tillsammans med Claude.
Kodfrågorna är testade i Node och Chromium mot kursens labbapp
([digital-platform-lab](https://github.com/MatteoDiAmare/digital-platform-lab)).
